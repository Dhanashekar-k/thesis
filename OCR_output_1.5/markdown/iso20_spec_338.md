###### 8.3.5.5.4 Scheduled_DC_CLReqControlModeType

This type contains all elements of the DC_ChargeLoopReq message that are only required in case the control mode Scheduled is chosen.

[V2G20-1760] The SECC and the EVCC shall implement this type as defined in Figure 183 and Table 174.
