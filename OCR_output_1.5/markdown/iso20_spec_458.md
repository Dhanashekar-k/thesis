Some requirements in this document may allow the relying party/validating entity to ignore certain critical/non-critical extensions even if they are present and the relying party/validating entity is able to recognize/interpret and process them. Those requirements will make it clear when the relying party can ignore the extensions and which exact extensions can be ignored.

Similarly, some requirements in this document may mandate the relying party/validating entity to process certain critical/non-critical extensions even if they are marked as non-critical. Those requirements will make it clear when the relying party is mandated to process the extensions and which exact extensions are mandated to be processed.

#### B.2.3 Common requirements for all certificate profiles

Per ITU-T X.509 and IETF RFC 5280 (as updated by IETF RFC 6818, IETF RFC 8398 and IETF RFC 8399), every x.509v3 certificate will contain basic certificate fields "TbsCertificate", "SignatureAlgorithm" and "SignatureValue". If any of these fields are not present in the certificate or if the relying party/validating entity is unable to process any of these fields, the relying party will reject the certificate.
