[V2G20-2555] Once a new SessionID has been assigned to the V2G Session, the EVCC should calculate SHA512 hash of the SessionID of the V2G session concatenated with the hash generated by [V2G20-2635]. Refer to [V2G20-2106], [V2G20-2626] and [V2G20-2627] for details of SessionID assignment.

NOTE 5 SessionIDtoSECCCertificateBinding = SHA512 (SessionID || SHA512 (SECC/PE certificate)).

[V2G20-2556] The EVCC should discard the hash generated by [V2G20-2635] after the hash has been utilized per [V2G20-2555].

[V2G20-2557] The EVCC should securely store the hash generated by [V2G20-2555] until the V2G session associated with the particular SessionID is terminated/closed.

[V2G20-2558] Whenever the EVCC performs the "Full Handshake" (as described in 7.7.3.5) to setup a TLS session (as described in 7.7.3.3, 7.7.3.4 and 7.7.3.5), it shall calculate a new session binding by following [V2G20-2635].

[V2G20-2637] The EVCC should securely store the hash generated by [V2G20-2558] until it is used per [V2G20-2638].

[V2G20-2638] When the EVCC receives the SessionID value in the SessionSetupRes for the V2G communication session that it is trying to resume, the EVCC should calculate the SHA512 hash of the SessionID received in SessionSetupRes message concatenated with the hash generated by [V2G20-2558].

NOTE 6 ReceivedSessionIDtoSECCCertificateBinding = SHA512 (SessionID || SHA512 (SECC/PE certificate)).

[V2G20-2639] The EVCC should discard the hash generated by [V2G20-2558] after the hash has been utilized per [V2G20-2638] or when the associated V2G communication session is terminated.

[V2G20-2559] The EVCC should check that the hash value calculated by [V2G20-2638] is the same as the hash value calculated by [V2G20-2555].

8.3.4.2 V2G session standby

[V2G20-1194] To enter a standby period, the EVCC shall stop charging (no current drawn by EV) before sending a PowerDeliveryReq message with ChargeProgress set to "Standby".

[V2G20-2100] During a standby period with conductive charging and ACD, the physical connection shall be maintained throughout the entire service session.

NOTE Any physical disconnection, for example, removal of the connector, results in abortion of the service session.
