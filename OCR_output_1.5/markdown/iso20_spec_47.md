NOTE 116 bits of entropy is based on 0,9 bits of entropy/bit generated by the RBG for a 128 bit number.

### 7.4 V2G communication states and data link handling

V2G messaging on application layer requires the establishment of the lower layer protocols to enable V2G message exchange between the EVCC and SECC. This document focuses on protocols above the data link layer. The data link layer is described in ISO 15118-3 and ISO 15118-8.

This subclause defines the basic requirements for establishing communication above the data link layer. This document does not imply any implementation. The figures in this subclause only show the basic sequencing for managing the protocol stack.

The timer, timeout and performance time values used in this subclause are described in 8.6 and its subclauses. Figure 8 depicts the general communication states of the V2G communication from an EVCC perspective. The following applies for the EVCC:

[V2G20-014] After the data link layer connection is established (D-LINK_READY.indication(DLINKSTATUS=Link established)), the EVCC shall initiate the IP address assignment mechanism as defined in 7.6.3.2 and 7.6.3.3.

[V2G20-016] The EVCC shall process the IP address assignment mechanism as defined in 7.6.3.2 and 7.6.3.3.

[V2G20-018] After a link-local IP address is assigned, the EVCC shall start the process for discovering the SECC address as defined in 7.10.1.

[V2G20-019] The EVCC shall start the SDP client according to 7.10.1.

[V2G20-1804] After receiving an SDP response with transport protocol set to TCP and security option set to TLS, the EVCC shall establish the TLS connection to the SECC as described in 7.7.3.

[V2G20-1805] If [V2G20-1804] is not fulfilled, then ISO 15118-20 (this document) shall not be offered by the EVCC during SupportedAppProtocolReq or selected by the SECC in SupportedAppProtocolRes. Refer to Table 5 for further details of services/standards that can be supported in such a condition.

[V2G20-024] After the TLS connection is established, the EVCC shall initiate the V2G communication session as defined in Clause 8.

[V2G20-025] The EVCC shall terminate the TLS connection after stopping the V2G communication session.

[V2G20-717] If the EVCC sent the message SessionStopReq with parameter ChargingSession equal to "Terminate" it shall terminate the Data-Link (D-LINK_TERMINATE.request()) after receiving the message SessionStopRes.

[V2G20-1227] If the EVCC sent the message SessionStopReq with parameter ChargingSession equal to "Pause" it shall pause the Data-Link (D-LINK_PAUSE.request()) after receiving the message SessionStopRes with ResponseCode set to "OK" and follow the sleep and wake-up requirements defined in ISO 15118-3:2015, 7.6.

[V2G20-719] Whenever the EVCC receives the indication for a missing Data-Link (D-LINK_READY.indication(DLINKSTATUS=No link)), the EVCC shall continue with [V2G20-014].
