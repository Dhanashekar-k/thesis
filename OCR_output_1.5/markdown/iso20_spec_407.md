##### 8.6.3.2 AC requirements

[V2G20-1619] The message "AC_ChargeParameterDiscoveryRes" shall contain the ResponseCode "FAILED_WrongChargeParameter" if the content of attribute "EV_EnergyTransferParameter" in the AC_ChargeParameterDiscoveryReq message is not valid, for example, wrong parameter set is provided, one or multiple parameters cannot be interpreted.

[V2G20-1948] The message AC_ChargeLoopRes shall contain the ResponseCode "WARNING_EVPowerProfileViolation" if a violation of the PowerTolerance band was detected according to the conditions defined in [V2G20-1864].

[V2G20-1951] The message AC_ChargeLoopRes shall contain the ResponseCode "FAILED_EVPowerProfileViolation" if a violation of the PowerTolerance band was detected according to the conditions defined in [V2G20-1865].

[V2G20-1990] The message "MeteringConfirmationRes" shall contain the ResponseCode "FAILED_MeteringSignatureNotValid" if the SECC is not able to validate the signature, or the contained meter reading does not fit to the provided meter reading during "AC_ChargeLoopRes" and the SECC requires that the signature is valid.
