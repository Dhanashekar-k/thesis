NOTE 1 ECParameters is simply a container that contains the parameter values for the selected algorithm.

NOTE 2 OID values for "ecdsa-with-SHA512", "id-ecPublicKey" and "secp521r1" can be found in B.1.

Although including "keyPurposeId" (as part of "ExtendedKeyUsage") is mentioned as optional, it is highly recommended to include this parameter in the SECC certificate. This makes the certificate more secure and prevents its misuse.
