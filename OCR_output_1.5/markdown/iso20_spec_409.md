##### 8.6.3.4 WPT requirements

[V2G20-5122] The message "WPT_ChargeParameterDiscoveryRes" shall contain the ResponseCode "FAILED_WrongChargeParameter" if the content of attribute "EV_EnergyTransferParameter" in the WPT_ChargeParameterDiscoveryReq message is not valid, for example, wrong parameter set is provided, one or multiple parameters cannot be interpreted.

[V2G20-5074] The message "PowerDeliveryRes" shall contain the ResponseCode "WARNING_WPT" after the supply device has detected an alignment error or other anomaly.

[V2G20-5075] The message "WPT_ChargeLoopRes" shall contain the ResponseCode "WARNING_WPT" after the supply device has detected an alignment error or other anomaly.

[V2G20-5076] The message "WPT_ChargeLoopRes" shall contain the ResponseCode "FAILED" after the supply device has detected an unrecoverable error or exception.

[V2G20-5077] The message "WPT_AlignmentCheckRes" shall contain the ResponseCode "WARNING_WPT" after the supply device has detected an alignment error.

[V2G20-5056] If the SECC has received the WPT_FinePositioningReq message with the parameter EVResultCode set to a "EVResultFailed" it shall respond with a WPT_FinePositioningRes message with the parameter ResponseCode equal to FAILED or WARNING_WPT.
