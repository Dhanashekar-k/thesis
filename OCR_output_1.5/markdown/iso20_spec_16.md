Note 1 to entry: In this case during EV charging session (3.7).

Note 2 to entry: The values for active/reactive energy, active/reactive power, current, power factor, based on timing slot can be recorded. The values are monitored remotely, so they can be programmed to manage the power (for example, reducing or modulating it). Furthermore, the values can share the information with DSO and other devices based on PLC communication.

### 3.57 

## sub-CA

subordinate certificate authority which issues, e.g. SECC certificates (3.48) and/or contract certificates (3.11) on behalf of a root CA such as V2G root CA (3.70) or e-mobility service provider root CA (the latter only for contract certificates)

Note 1 to entry: The ability of issuing the certificates are delegated from a root CA and a root CA can revoke the sub-CA at any time.

### 3.60 

## timeout

timing requirement defining the time a V2G entity (3.65) monitors the communication system for a certain event to occur

Note 1 to entry: If the specified time is exceeded, the respective V2G entity (3.65) initiates the related error handling. This is a fixed-time value.

### 3.61 

## timer

device or piece of software used in an implementation for measuring time

Note 1 to entry: Depending on the specific use case a timer is used to trigger certain system events.

### 3.62 

## vehicle certificate

leaf certificate (3.5) issued to an EVCC (3.21) by an OEM (3.36) or V2G (3.63), which is used in TLS so that the SECC (3.47) can verify the authenticity of the EVCC

Note 1 to entry: This certificate is also used for binding between different TLS sessions that belong to the same V2G session by SECC.
