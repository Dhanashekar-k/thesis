[V2G20-1972] After receiving the CertificateInstallationReq, if the data required for the CertificateInstallationRes is not yet available, the SECC shall respond with a CertificateInstallationRes with EVSEProcessing set to "Ongoing" within V2G_SECC_Msg_Performance_Time according to Table 215. The next allowed request shall be CertificateInstallationReq and the V2G_SECC_Sequence_Timeout is set according to Table 215.

[V2G20-1973] After receiving the CertificateInstallationReq, if the data required for the CertificateInstallationRes is available and additional contract certificate chains are available, the SECC shall respond with a CertificateInstallationRes with RemainingContractCertificateChains set to the number of remaining contract certificate chains and EVSEProcessing set to "Finished" within V2G_SECC_Msg_Performance_Time according to Table 215. The next allowed request shall be CertificateInstallationReq or AuthorizationReq and the V2G_SECC_Sequence_Timeout is set according to Table 215.

[V2G20-1974] The SECC shall not provide more contract certificate chains than supported by the EVCC, which was communicated by the EVCC in the CertificateInstallationReq through the parameter MaximumContractCertificateChains.

[V2G20-1975] After receiving the CertificateInstallationReq, if the data required for the CertificateInstallationRes is available and no additional contract certificate chains are available, the SECC shall respond with a CertificateInstallationRes with EVSEProcessing set to "Finished" and RemainingContractCertificateChains set to "0" within V2G_SECC_Msg_Performance_Time according to Table 215. The next allowed request shall be AuthorizationReq and the V2G_SECC_Sequence_Timeout is set according to Table 215.
