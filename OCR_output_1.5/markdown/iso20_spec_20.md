## 5 Conventions

### 5.1 Definition of OSI based services

This document is based on the conventions defined in the OSI service conventions (refer to ISO/IEC 10731) as they apply for the individual layers specified in this document.

This document describes requirements applicable to layer 3 – 7 according to the OSI layered architecture.

### 5.2 Requirement structure

This document uses the requirement structure defined here. A unique number identifies each individual requirement defined in this document. Systematic and ordered requirement structure enables readers to find the target requirement number easily.

The following format is applied for new defined and updated requirements:
