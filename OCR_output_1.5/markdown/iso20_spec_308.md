[V2G20-1346] The EVSE shall calculate the Power values in the ScheduleTuple based on the parameter EVSENominalVoltage.

[V2G20-1347] The EVCC shall use the value EVSENominalVoltage provided by the SECC to calculate the maximum available charging current based on the Power values provided in the PowerSchedule of the ScheduleExchangeRes and the Power values in the element EVPowerProfile of the PowerDeliveryReq message.

[V2G20-1828] When charging or discharging the EV shall respect the maximum power imbalance between all 3 phases (utilized or not) using the limit defined by Maximum Power Asymmetry. This, however, shall not apply if the power asymmetry is the result of a technique which implements a grid code requirement that has a higher priority than the static Maximum Power Asymmetry parameter.

NOTE 1 If the element MaximumPowerAsymmetry is not present, no asymmetric limitation applies.

NOTE 2 One example for a higher priority grid code requirement would arise from the fact that asymmetry limits typically apply to the grid connection point. So if the energy management of the building sees extreme asymmetries it might compensate them. In the ISO 15118 series this would be communicated via phase specific EVSETargetActivePower(_L2/L3) values, which would override the default behavior defined in the MaximumPowerAsymmetry.
