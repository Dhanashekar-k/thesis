## Annex A (normative)

## Schema definition

The V2G application layer message specification consists of the following XML Schema documents with the following scope:

– "V2G_CI_AppProtocol": defines the protocol handshake (SAP) messages. The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_AppProtocol.xsd;

– "V2G_CI_CommonTypes": defines the common types used by all defined messages (except SAP). The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_CommonTypes.xsd;

– "V2G_CI_CommonMessages": defines the common messages that are not specific to any energy transfer mode. The XSD file can be downloaded from: https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_CommonMessages.xsd;

– "V2G_CI_AC": defines the messages exclusively used for AC charging. The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_AC.xsd;

– "V2G_CI_DC": defines the messages exclusively used for DC charging. The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_DC.xsd;

– "V2G_CI_ACDP": defines the messages exclusively used for ACDP. The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_ACDP.xsd;

– "V2G_CI_WPT": defines the messages exclusively used for WPT. The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/V2G_CI_WPT.xsd;

– "xmldsig-core-schema": defines the W3C schema for XML signatures. The XSD file can be downloaded from:

https://standards.iso.org/iso/15118/-20/ed-1/en/xmldsig-core-schema.xsd.
