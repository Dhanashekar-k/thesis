#### 7.3.5 Firewall

This subclause defines firewall functionality, where the term firewall refers to the definition made in ISO/IEC 27033-1. The firewall specified here separates the trusted from the untrusted network, where trusted and untrusted are defined as follows.

Trusted network SECCs and SDP servers are part of the trusted network. Access to this network is controlled by the EVSE operator. Only authorized nodes of the operator have access to this network.

Untrusted network EVCCs are part of the untrusted network. Access to this network is not controlled by the EVSE operator.

[V2G20-1013] There shall be at least one firewall between the EVCC, which is connected to an untrusted network, and the SECC, which is connected to a trusted network.

[V2G20-1014] For security reasons the rules mentioned in Table 3 shall apply for the firewall mentioned in [V2G20-1013].
