NOTE It is up to the implementation whether to give a response code FAILED or WARNING_WPT: In case of FAILED, the communication will be terminated. In case of WARNING_WPT, the system allows to repeat the positioning procedure.

[V2G20-5078] The message WPT_ChargeLoopRes shall contain the ResponseCode "WARNING_EVPowerProfileViolation" if a violation of the PowerTolerance band was detected according to the conditions defined in [V2G20-1864].

[V2G20-5079] The message WPT_ChargeLoopRes shall contain the ResponseCode "FAILED_EVPowerProfileViolation" if a violation of the PowerTolerance band was detected according to the conditions defined in [V2G20-1865].
