##### 8.6.3.3 DC requirements

[V2G20-2272] The message "DC_ChargeParameterDiscoveryRes" shall contain the ResponseCode "FAILED_WrongChargeParameter" if the content of attribute "EV_EnergyTransferParameter" in the DC_ChargeParameterDiscoveryReq message is not valid, for example, wrong parameter set is provided, one or multiple parameters cannot be interpreted.

[V2G20-1947] The message DC_ChargeLoopRes shall contain the ResponseCode "WARNING_EVPowerProfileViolation" if a violation of the PowerTolerance band was detected according to the conditions defined in [V2G20-1864].

[V2G20-1950] The message DC_ChargeLoopRes shall contain the ResponseCode "FAILED_EVPowerProfileViolation" if a violation of the PowerTolerance band was detected according to the conditions defined in [V2G20-1865].
